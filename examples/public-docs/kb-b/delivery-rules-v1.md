# 阶段交付与验收规则（B 库）

演示规则，非真实客户数据。此文档与 A 团队的同名规则属于不同知识库、不同逻辑文档，不能按标题合并，也不能跨库借用。

## B-D1-01 范围与期限

本规则适用于 B 团队自 2026-10-01 起的完整阶段提交。完整提交包含交付物链接和验收清单。接收方应从完整提交的次一自然日起 7 个自然日内回复，截止为最后一日 18:00（Asia/Shanghai）。

自然日包含周六和周日；此期限不是 A 团队的 3 个工作日规则。

## B-D1-02 逾期与争议

到期未回复时登记 B 团队人工协调工单，不另设 A 团队的提醒后 2 个工作日等待步骤。逾期不自动通过，不自动付款。争议交人工核对，本规则没有退款比例或赔偿金额条款。
