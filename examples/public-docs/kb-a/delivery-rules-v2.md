# 阶段交付与验收规则（A 库，当前 v2）

演示规则，非真实客户数据，不用于处理真实项目争议。

## A-D2-01 适用范围与版本

本规则适用于 A 团队自 2026-10-01 起提交的阶段交付，替代同一逻辑文档的 v1 作为当前规则。它不自动追溯变更旧提交的约定。缺少提交日期或团队归属时，应先澄清；当前默认检索不将历史 v1 混入证据。

## A-D2-02 完整交付与验收期限

完整交付必须含交付物链接、版本说明和对应验收项清单。接收方应从完整交付的次一工作日起 3 个工作日内给出意见，截止时点为最后一日 18:00（Asia/Shanghai）。

演示中的工作日仅指周一至周五，不考虑法定节假日和调休。资料不完整时先补齐，不根据缺失资料推算验收期限。

## A-D2-03 未回复的处理

验收期满无意见时，交付方发送一次书面提醒；从提醒后的次一工作日起再等待 2 个工作日。仍无回复时，按 [整改与人工处理手册](rectification-manual.md) 的 A-R-03 登记人工协调。

逾期不会自动验收通过，也不会授权助手执行付款、退款或处罚。

## A-D2-04 退回和再次提交

接收方退回时应逐项写明不满足的验收项与可核对证据。交付方按 [整改与人工处理手册](rectification-manual.md) 的 A-R-02 准备整改清单；再次提交齐全材料后，重新按 A-D2-02 的 3 个工作日计算验收期。

## A-D2-05 必须人工介入与未规定事项

双方对验收标准、证据真实性或交付范围发生争议，或收到涉嫌泄露团队资料的报告时，转人工处理。登记所需资料见 A-R-03。

本规则未规定退款比例、赔偿金额或真实业务争议的裁决结果，不能据此推导这些答案。
