# 整改与人工处理手册（A 库）

演示规则，非真实客户数据。配套 [当前交付规则 v2](delivery-rules-v2.md) 使用。

## A-R-01 整改入口

接收方将退回意见逐项关联到原验收清单，并附可核对的证据。交付方保留退回意见与原交付版本，不能覆盖旧记录来隐藏问题。

## A-R-02 再次提交清单

再次提交至少包含五项：原验收项、问题证据、修复说明、对应新交付物、尚未解决项。若无尚未解决项，也应明确填“无”，不能留空冒充已全部解决。

材料完整后按 A-D2-04 重新进入验收，期限沿用 A-D2-02 的 3 个工作日。本手册不另设整改完成天数；不知道整改工作量时应补充条件或协商。

## A-R-03 人工协调登记

两类入口：一是验收期满提醒后，再等待 2 个工作日仍无回复；二是双方对标准、范围、证据真实性有争议，或出现涉嫌资料泄露的报告。

登记材料包含阶段标识、提交日期、适用规则版本、双方意见及现有证据链接。协调人员核查资料并给出下一步安排；知识助手只提供依据，不自动裁决、处罚或执行资金操作。

## A-R-04 资料与访问

登记只引用当前成员有权访问的资料。不要把另一个团队的内部文档复制进协调说明。访问权由服务端成员关系决定，文档中提到另一个团队不代表获得其权限。
