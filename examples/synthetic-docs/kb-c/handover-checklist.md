# 外包交付操作与交接清单（C 库）

演示规则，非真实客户数据。本清单给出供应商交付的操作步骤；期限与要件以 C 库规则（C-D1 系列）为准，本清单不改变任何数值。

## C-O1-01 清单定位

本清单回答"怎么交、交给谁、留什么痕"；规则性问询回到 C-D1 系列条款。两者冲突时以规则为准。

## C-O1-02 交付前自检

提交前核对三项：成果链接可打开、交付说明写清范围与变更点、验收对照表与成果逐条对应。任一项缺失先补齐再提交。

## C-O1-03 提交渠道

演示环境中供应商通过 C 团队门户提交；提交后保存回执编号。聊天窗口传文件不构成正式交付。

## C-O1-04 提交时间口径

期限按工作日计、18:00（Asia/Shanghai）为日界参考；为避免起算争议，建议在工作日 18:00 前完成提交。到期侧口径以 C-D1-03、C-D1-04 为准。

## C-O1-05 交付说明写法

交付说明包含：本次范围、相对上次的变更点、已知限制。缺"已知限制"的说明可被要求补正。

## C-O1-06 验收对照表要求

对照表逐条列出验收项、对应成果位置与核对方式；C 团队按表逐项验收，表与成果对不上时退回补正。

## C-O1-07 提醒后的动作（口径复述）

验收期满无意见时，供应商发一次书面提醒并附回执编号；从提醒的下一个工作日再等 2 个工作日，期满无回复即登记人工协调。依据 C-D1-05。

## C-O1-08 退回后的整改提交

按退回意见整理四项材料（问题清单、修正说明、更新后成果、验证记录），经门户再次提交并注明"再次提交"；齐备后重新计算 3 个工作日。依据 C-D1-07。

## C-O1-09 对账与记录

每阶段归档回执、提醒函、退回意见与整改材料；归档只增不删，不覆盖历史版本。对账本身不产生结算数值。

## C-O1-10 联系人与升级

门户内登记双方联系人；无法按清单推进时升级到人工协调，登记材料参照 C-D1-07 并附双方意见。

## C-O1-11 效力关系

本清单是操作层文档：不设期限、不定要件、不创设答案。引用时给到 C-D1 系列条款号，不把本清单的步骤当期限依据。
