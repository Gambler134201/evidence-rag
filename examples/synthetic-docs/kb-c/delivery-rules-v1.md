# 外包交付与验收规则（C 库，当前 v1）

演示规则，非真实客户数据。C 库是独立知识库，收录 C 团队与其外包供应商之间的交付约定；与 A 库、B 库的规则同题材但不同源，条款编号、适用对象、知识库归属都不同，不能跨库借用或按标题合并。

## C-D1-01 适用对象与范围

本规则适用于供应商自 2026-10-01 起向 C 团队提交的成果交付。C 团队成员之间的内部协作、其他团队的交付都不适用本规则；对象不明时先澄清。

## C-D1-02 完整交付要素

供应商交付时应同时提供：成果访问链接、交付说明（写明范围与变更点）、验收对照表。三样缺一即视为未完成交付，期限从补齐后才开始计算。

## C-D1-03 验收期限

C 团队从完整交付的次一工作日起 **3 个工作日**内给出验收意见，截止为最后一日 18:00（Asia/Shanghai）。

## C-D1-04 期限计算口径

工作日仅指周一至周五，演示口径不含法定节假日与调休；期限连续计数，跨周、跨月都按日历顺序继续。

## C-D1-05 未回复的处理

期满无意见时，供应商发出一次书面提醒；从提醒后的次一工作日起再等 **2 个工作日**，仍无回复即登记人工协调。

## C-D1-06 逾期效果

逾期不等于验收通过，不触发自动付款或结算，也不产生处罚数值；沉默不改变任何一方的义务。

## C-D1-07 退回与再提交

退回意见逐项对应验收对照表；供应商整改后再次提交四项材料：问题清单、修正说明、更新后成果、验证记录。再次提交齐备后按 C-D1-03 重新计算 3 个工作日。本规则不设统一的整改完成天数。

## C-D1-08 多供应商场景

C 团队可能同时与多家供应商合作；各家交付相互独立，一家的问题处理方式不自动适用于另一家。

## C-D1-09 权限与跨库边界

只有 kb-c 成员或另有 kb-c 授权的身份才能检索本库原文；最终判定由服务端成员关系完成，自报身份无效。

## C-D1-10 与其他库的相似性说明

本库部分期限数值可能与 A 库现行规则相同，但适用对象、条款编号与知识库归属完全不同；数值巧合不构成引用依据，回答 C 相关问询只引 C 库条款。

## C-D1-11 未规定事项

本库没有退款比例、赔偿金额、违约金、保证金或结算比例条款；此类问询应答"无依据"并转人工处理。
