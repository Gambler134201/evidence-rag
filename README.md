# 知据 / evidence-rag

面向小型团队的可溯源知识助手：从有效且有权限的文档中回答问题，提供可核对的原文引用。

当前处于实施规划阶段，应用代码尚未开发。技术方案为 Next.js + TypeScript、FastAPI + Pydantic、PostgreSQL + pgvector；先建立向量检索基线，再按评测决定混合检索与重排。

- [实施任务清单：任务编号、依赖、交付物与 P0 对应关系](docs/implementation-backlog.md)

Git 已初始化，主分支为 `main`。后续按可验收阶段开发和提交；密钥、原始上传资料、数据库、本地工作台记录与私有运行输出不进入版本管理。公开示例、冻结评测数据和经检查的报告可以纳入仓库。
