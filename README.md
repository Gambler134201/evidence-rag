## 开发方法

本项目用自建多模型工作台开发：执行模型产出实现与草稿，主脑按可判定验收条件独立验收，不采信执行模型自报的“已完成”；评测先行，规划指标与实测结果分开记录。AI 产出的评审、夹具等材料在 `PROVENANCE.md` 登记来源与哈希；采纳的结论改写进自己的文档，未采纳的保留标注或删除。

Git 已初始化，主分支为 `main`。后续按可验收阶段开发和提交；密钥、原始上传资料、数据库、本地工作台记录与私有运行输出不进入版本管理。公开示例、冻结评测数据和经检查的报告可以纳入仓库。

安装、启动和真实模型调用命令将在对应实现与验证完成后补充。规划指标不代表已取得的成果。
