## 0. 使用约定

**任务状态取值**（每个任务当前默认 `未开始`）：
`未开始` / `待授权`（需用户或主脑先给决定或预算）/ `进行中` / `待验收` / `已完成` / `受阻`

**“可判定验收条件”的判定方式标签**：
- `AUTO`：自动测试或脚本返回预期结果（pytest、断言、退出码）
- `FILE`：指定文件/字段/记录存在且内容符合结构要求
- `MANUAL`：按清单人工核对，逐条打勾并留证据（截图、日志、记录）
- `REVIEW`：评测或运行报告中含指定字段与数值（数值须来自真实运行）

**门禁规则**
1. 上一阶段依赖能力未通过验收，不将后续依赖能力标为完成；允许独立的离线准备。真实模型未确认时可做骨架和 mock，不算真实链路完成。每阶段结束产出“已完成 / 未验证 / 未完成”三态清单。
2. 验收只检查本阶段相关改动，不反复跑整套评测；真实模型回归集中执行，单元/集成测试默认 mock。
3. 任何规划指标不得提前写成实测成果；缺数据写“未知”，不填 0。
4. 不承诺固定工期，不承诺固定准确率或延迟秒数。
