# 评测口径 v0.1（S0-T07）

编制：2026-10-24。整合原规划 §7、实施方案 §9、`evals/badcase-taxonomy.md`；六类归因与金标核对规则以 2026-10-24 采纳后的 backlog 为准。状态：待验收。

## 1. 指标定义与计算式

| 指标 | 计算式 | 门槛（目标，非成绩） |
|---|---|---|
| Evidence Recall@5 | Σ min(命中必需证据数, 必需证据总数) / Σ 必需证据总数，按题平均；gold 锚定不可变 version_id+原文位置，映射到当前构建 chunks | 留出集可回答题 ≥85% |
| 回答通过率 | 必需信息点齐、无关键编造、满足题目要求的题数 / 可回答题数 | ≥75% |
| 引用支持率 | 人工判定被引用原文支持的结论数 / 带引用结论数 | ≥90%，另报引用缺失数 |
| 无答案处理正确率 | 正确拒答或合理澄清数 / 无答案类题数 | ≥90%，报告样本量 |
| 计算类正确率 | 列出工作日序列且结果正确数 / 计算类题数（只给日期不算过） | 单列，不入 Recall |
| 澄清正确率 | 先澄清且问题具体数 / 澄清类题数（直接给天数即失败） | 单列 |
| 回答稳定性 | 同题 n≥3 次运行的状态一致率（2026-10-24 A/B 实测：思考型模型温度 0 下仍有路径差异，单次运行不可作结论） | 单列，正式 A/B 每题 n≥3 |
| 注入抵抗 | 正确处理干扰样本数 / 干扰类题数 | 单列，标注 mock 或真实模型 |
| 权限/生命周期断言 | 可重复后端检查通过数 | ≥20 项全过，独立于问答分母 |
| 性能与成本 | P50/P95、检索/生成分段耗时、token、费用或"未知" | 可测可追，不预设 |

## 2. 数据集与冻结策略

- 主集 80 条：事实 30 / 跨段跨文档 20 / 新旧版本 10 / 无答案澄清 10 / 干扰 10；开发集与留出集各 40，按问题族切分、近似改写去重。
- 冒烟集 10 条已于 2026-10-24 经作者复核转正：正式集 `evals/datasets/smoke-10.jsonl`，核对记录 `evals/gold-review.md`（6 项口径决策：smk-02/05 干扰词修正、smk-03 归澄清类、smk-04 否定式不算泄露、smk-09 字面冲突消除、smk-10 记 G2 badcase）。原始草稿 `smoke-10-draft.jsonl` 归档。
- 先冻结留出集；看结果调参须保留旧报告并另备新留出集。
- 语料有效性验收（S1-T12）：总条款 153（达标 150–250）、干扰 ≥30%（实测 41–60% 双口径）；纯向量基线 Recall@5 应落在 60–85%，>90% 判干扰不足退回扩充。

## 3. 评分与归因

- 每条失败归且只归一类：R1/R2/P/G1/G2/G3（定义与报告格式见 badcase-taxonomy §1）；R1/R2 用 top-20 候选机械区分，G 类人工判定。
- 人工评分留理由与示例，核对人如实写 author（`evals/gold-review.md` 模板，待建）；执行模型自评不算核对。
- LLM 评审仅辅助并抽查不一致项；同时统计可回答题被误拒数。
- 小样本结果不外推为企业准确率；缺数据记"未知"不填 0。

## 4. 现状（诚实边界）

- 2026-10-25（阶段 B 实验）：dev 集纯检索扫描——vector@5 82.8%、**vector@8 87.9%**、hybrid-rrf40@5 86.2%、**重排（vector top-20 → bge-reranker → top-5）87.9%**：重排以 top-5 成本达到 top-8 的召回上限，精确覆盖 R2 类失败；RRF k 值不敏感。报告 `evals/results/phase-b-experiments.md`。
- 2026-10-25：**80 条冻结主集正式 A/B 已完成**（每题 n=3，真实模型）：留出集稳定通过率 vector **92.5%** / hybrid 82.5%；Evidence Recall@5（锚点级）vector **81.0%** / hybrid 74.6%，三轮零波动；时延 P50 8.5~10.4s。混合检索未显优势（近邻干扰语料词汇重叠吸引 BM25 通道），默认模式维持向量。系统性失败题（m67/m68 应澄清未澄清、m36 检索不足等）已列为下一轮优化素材。报告：`evals/results/formal-ab/report.md`。数字不外推为企业准确率。
